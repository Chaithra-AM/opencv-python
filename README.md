# Python OpenCV Programs

This repository contains six Python programs implemented using OpenCV.

## Programs

### 1. Web Camera
Displays live video captured from the computer's webcam.

### 2. Color Stripes
Creates an image containing different colored stripes using OpenCV.

### 3. Mouse Click - Draw Shapes
Allows the user to draw rectangles and circles using mouse clicks and dragging.

### 4. Color Recognition Mask
Uses HSV color detection and masking to recognize a selected color from the webcam feed.

### 5. Live Webcam Drawing
Allows the user to draw lines over a live webcam video using the mouse.

### 6. Car Motion Video Using Frames
Creates and processes a car-motion video frame by frame using OpenCV.

## Technologies Used

- Python
- OpenCV
- NumPy

## Controls

- `Q` - Quit
- `R` - Rectangle
- `C` - Circle
- Left Mouse Button - Draw
